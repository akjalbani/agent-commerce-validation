INTERPRETATION

Method and limitations

What this model establishes, and what it does not establish.

Research model

Fixed mandate: principal research-user, payee approved-api, asset USD, 50-unit individual cap, 80-unit total cap and simulated expiry at clock 200. Rejected requests do not reserve budget.

What is measured

Logical conformance of policy decisions to expected synthetic outcomes, including replay identity, aggregate budget, expiry, payee checks and reservation during reconciliation.

What is not measured

Real settlement, cryptographic mandate authenticity, payment protocol conformance, performance, infrastructure resilience, merchant disputes, bank finality, fraud prevention or regulatory compliance.

Reproducibility

The Python suite is executed with python -m unittest discover -s tests -v. The browser suite independently implements comparable case logic. Results should not be reported as identical code execution across Python and JavaScript.
